# ke-rent-filter · 租房筛选助手（贝壳 / 安居客）

一个帮**租客**和**租赁中介**更快挑房、比房的浏览器小工具（Tampermonkey 用户脚本）。

在[贝壳地图找房](https://map.ke.com/map/310000/ZF)和[安居客地图找房](https://sh.zu.anjuke.com/ditu/)页面右侧加一个面板：按**面积、到某地的距离、每平米租金**整理你正在看的房源，把结果标在地图上，再配上楼层、电梯、停车等信息，方便横向比较、记下中意的房子。

它只是一个辅助你浏览的工具：
- 不改动任何房源信息，所有数据都来自你在页面上本来就能看到的内容
- 数据只保存在你自己的浏览器里，不上传到任何地方
- 访问节奏刻意放慢，和正常翻页浏览相当

## 它能帮你做什么

| 需求 | 说明 |
|---|---|
| **按面积挑房** | 「几居」和实际面积常常对不上，直接按 ㎡ 筛选更准 |
| **按通勤时间挑房** | 以公司、学校等任意地点为终点，按真实路线算自行车 / 步行 / 地铁+自行车的通勤时间 |
| **比较性价比** | 自动算出每平米租金，排序、着色一目了然 |
| **看房龄** | 你在安居客浏览小区页时自动记下竣工年份，筛「2010 年后」的次新小区 |
| **看停车条件** | 标出小区有没有自有停车场（地下 / 地上），以及最近的公共停车场有多远 |
| **整理候选清单** | 收藏、隐藏、拉黑整个小区、关键词排除，导出 CSV 发给家人或客户 |

## 安装

1. 浏览器装 [Tampermonkey](https://www.tampermonkey.net/)
2. 点这里安装：[ke-rent-filter.user.js](https://raw.githubusercontent.com/zhang-dc/ke-rent-filter/main/ke-rent-filter.user.js)
   （或在 Tampermonkey 里新建脚本，把文件全文粘进去保存）
3. 打开任一平台的租房地图，右侧出现面板：
   - 贝壳：登录后打开 <https://map.ke.com/map/310000/ZF>（上海）
   - 安居客：打开 <https://sh.zu.anjuke.com/ditu/>（上海）

默认圆心是上海人民广场，输地名回车或在地图上右键即可改成你自己的位置。

### 两个平台

两个平台**各自在自己的地图上显示**，不混在一起：

| | 贝壳 | 安居客 |
|---|---|---|
| 查询方式 | 按面积从大到小查，低于面积下限就停 | 接口不能按面积排序，按最新发布每种户型取前 20 页，面积在本地筛 |
| 官方条件 | 方式 / 户型 / 朝向 / 楼层 / 亮点 / 电梯 | 方式 / 户型（朝向在结果筛选里筛） |
| 详情补全 ④ | 有 | 没有 |
| 上架时间 | 有（由房源编号推算） | 没有 |
| 自行车时间 | 百度骑行路线 | 页面上的百度地图版本没有骑行路线，按步行路线路程折算 |

两边**共用**：面积、租金、单价、半径、通勤上限、锚点、结果筛选、收藏和小区黑名单、安居客记下的房龄 / 车位比。查询结果、坐标和通勤缓存**各自独立**。

## 用法：按 ①②③ 顺序点

- **① 查询**：按面板里的条件（面积、租金、整租 / 合租、户型、朝向等）查询附近房源，十几秒到半分钟
- **② 定位**：按小区名在百度地图上找到位置，算出到你设定地点的直线距离
- **③ 画到地图**：把筛选后的房源按小区标在地图上，附上你的地点和半径圈；之后改任何筛选，地图自动同步；再点一次恢复原来的地图
- **🚲 通勤**：按百度地图路线规划，算每个小区到锚点的自行车、步行、地铁+自行车（接驳骑车）时间
- **🅿 查停车**：按小区在百度地图上查周边停车场，标出小区自有停车场（地下 / 地上）和最近公共停车场的距离
- **④ 详情补全**：逐套打开房源详情，补上楼层、电梯、车位、水电、燃气、入住时间、租期，并剔除已下架的房源。每套间隔约 0.7 秒，房源多时需要一点时间，可以随时停止、下次接着补
- **导出 CSV**：导出当前筛选结果

### 通勤筛选

- 「自行车≤ / 步行≤ / 地铁+骑≤」三个框填分钟数，**满足任一**就保留
- 地铁+自行车：只取纯地铁方案，进站前、出站后超过 300m 的步行换成骑车（每段多算 1 分钟取车还车），换乘仍按步行
- 表格「通勤」列显示最快的那种方式（骑 / 走 / 铁），鼠标悬停看三种方式的明细和地铁线路
- **预设「字节房补」**：一键设成自行车≤20、步行≤30、地铁+自行车≤20 分钟（满足任一），锚点请设成你的办公地点；半径会放大到 5km
- 时间是百度地图的路线估算，实际以出行为准

### 房龄（竣工年份）

贝壳地图的数据里没有房龄。脚本也会在安居客的小区页面上运行：你**自己浏览**安居客小区列表或小区详情时，页面上显示的竣工年份（详情页还有停车位、停车费、物业费）会被记下来，贝壳面板按小区名自动匹配，不会额外发请求。

- 表格「竣工」列：2010 年以后标绿；没记录的小区点「查↗」在安居客打开浏览一下就有了
- 结果筛选「房龄」：2015年后 / 2010–2014 / 2000–2009 / 2000年前
- 想一次补齐一个板块：在安居客打开「小区」→ 选区域和板块，翻完列表的几页即可

### 设地点（锚点）

- 在「锚点」框输地名，**按回车**，经纬度自动填好
- 或者直接**在地图上右键**，那个位置就是新锚点
- 锚点一改，距离立刻重算；超出原查询范围时面板会提示重新 ① 查询

### 结果筛选（即时生效）

- 面积 / 租金 / 元每平米 / 半径这几个数字框改了**立刻生效**
- **居室 / 类型 / 品牌 / 停车 / 房龄 / 上架**：选项按查到的房源自动生成，带套数
- **包含 / 排除关键词**：匹配标题、小区、标签、品牌、类型，比如排除「公寓 地下」
- **☆ 收藏 / ✕ 隐藏**：单套标记，下次打开还在；「只看★」「显示已隐藏/拉黑」开关
- **⛔ 拉黑小区**：看不上的小区一键拉黑，整个小区的房源以后都不再显示（重新查询也一样）。拉黑后状态栏可以撤销；点地图气泡聚焦某个小区时也能直接拉黑；结果筛选里的「已拉黑 N 个小区」可以逐个解除
- 「排除商水商电」需要先做 ④ 详情补全

### 上架时间

贝壳列表里不显示发布日期。房源编号（如 SH2218300938802692096）是按时间生成的，脚本据此推算出**首次挂牌日期**，放在表格「上架」列（点表头默认新的在前），结果筛选里可以按「7天内 / 30天内 / 90天内 / 更早」筛。

下架后重新上架、沿用老编号的房源会显示得比较早，仅供参考。

### 表格

- 默认是窄表，楼层 / 电梯 / 停车等信息显示在小区名下面一行
- 点标题栏的 **⇔** 切到宽表，每项信息单独一列，点表头排序
- 鼠标悬停在停车标签上，可以看到匹配到的停车场名称
- 「停车费↗」链接会在新标签打开安居客上这个小区的页面，可以查看停车费、车位数（工具本身不读取安居客的数据）

### 地图

- 同一小区的房源合并成**一个气泡**：`4690起 · 2套`；只有一套时显示面积
- 气泡颜色 = 小区最低每平米租金在当前结果里的档位（绿 → 蓝 → 橙 → 红，便宜 → 贵），图例在面板里
- 缩小时气泡变成彩色圆点，避免叠成一片；收藏的小区始终显示完整气泡
- **点气泡**：表格只看这个小区（再点或点 ✕ 取消）
- **悬停表格行**：高亮对应气泡；**点表格行**：地图移过去

### 本地缓存

小区位置、停车情况、房源详情和上次的查询结果都保存在浏览器本地（IndexedDB），刷新页面、重启浏览器后都还在，不用重复查询：

| 内容 | 按什么存 | 有效期 |
|---|---|---|
| 小区位置 | 小区 | 长期 |
| 停车情况 | 小区 | 60 天 |
| 通勤时间 | 小区 + 锚点 | 90 天 |
| 安居客小区信息 | 小区 | 长期（脚本存储） |
| 房源详情 | 房源 | 3 天（已下架的 7 天） |
| 上次查询结果 | — | 直到下次查询 |

想清空缓存：浏览器 Console 里运行 `__kef.clearCache()`。

### 遇到问题

浏览器 Console 里运行 `__kef.diag()` 可以看到面板的运行状态，`__kef.cacheStats()` 看缓存情况。欢迎提 [Issue](https://github.com/zhang-dc/ke-rent-filter/issues)。

## 关于停车数据

“有停车场”不等于“有车位”——老小区大多有个地上停车场，但几百户抢几十个车位。所以停车分两层：

1. **车位比（优先）**：来自安居客小区详情页的「停车位」，比如 `130(1:0.4)` 表示每户 0.4 个车位；没写比例时按 车位数 ÷ 总户数 算。≥0.8 为「车位充足」，0.4–0.8 为「车位一般」，<0.4 为「车位紧张」（不是每户都有车）。在安居客打开过小区详情页的小区才有
2. **百度地图（兜底）**：只能看出有没有以小区名命名的停车场，显示为「有车场·车位未知」「有地下车库·车位未知」或「无小区车场」

都**仅供参考**，具体以实地或中介、物业确认为准。
